Install on Android

The APK is installed directly, outside the Play Store, during the beta.

  1. Download the APK with the button above (version 1.0.0-beta.1).
  2. Allow installs from this source when Android asks. Open Settings, then Apps or Install unknown apps, and allow your browser or file manager.
  3. Open the APK file from your Downloads folder and tap Install.
  4. Sign in or register and start testing. Download the newest APK from this page when a new version is posted.
Requires Android 8.0 or newer. Your browser may warn that the file is from an unknown developer. This is expected for beta builds distributed outside the Play Store.
